# YOLO11 + ByteTrack 객체 추적

## 1. 개요

YOLO11과 ByteTrack을 이용해 웹캠 영상에서 객체를 인식하고, 객체별 ID와 위치 정보를 추적하는 코드입니다.
현재는 Windows 노트북 웹캠을 이용해 기본적인 객체 인식 및 추적 기능을 구현한 상태이며, 추적 결과를 CSV 파일로 저장하도록 구성했습니다.
추후 라즈베리파이에 적용할 예정으로, 현재 코드는 PC 환경에서 동작을 확인하기 위한 초기 버전입니다.

## 2. 구현 내용

- YOLO11n 모델을 이용한 실시간 객체 인식
- ByteTrack을 통한 객체별 ID 부여 및 추적
- 객체 중심 좌표(X, Y), 바운딩 박스 크기, 신뢰도 추출
- 탐지 시각 및 프레임 번호 기록
- 추적 결과 CSV 파일 저장

## 3. 실행 환경

- Windows
- Python 3.11 (Anaconda)
- Ultralytics
- OpenCV
- 노트북 내장 웹캠

필요한 패키지는 아래 명령어로 설치할 수 있습니다.

```bash
pip install ultralytics opencv-python
```

`yolo11n.pt` 모델 가중치 파일은 저장소 용량을 고려해 업로드하지 않았습니다. 최초 실행 시 자동으로 다운되므로 인터넷 연결이 필요합니다.

## 4. 실행 방법

프로젝트 최상위 폴더(`ai-door`)에서 아래 명령어를 실행합니다.

```bash
python vision/webcam_tracking.py
```

실행하면 웹캠 영상에서 인식된 객체의 바운딩 박스와 추적 ID가 표시됩니다.

웹캠 창에서 `q` 키 or ctrl+c 누르면 종료, 추적 결과는 CSV 파일로 저장됩니다.
CSV파일은 실행하면 새로운 파일로 덮어지므로 생성 후 파일명을 변경해주세요.

## 5. 추적 데이터

CSV 저장 위치:

`data/vision/tracking_results.csv`
**만일 실행 시 꼭 이름 변경해주세요.

| 항목 | 설명 |
|---|---|
| timestamp | 데이터 기록 시각 |
| elapsed_sec | 프로그램 실행 후 경과 시간(초) |
| frame_id | 프레임 번호 |
| track_id | ByteTrack에서 부여한 객체 ID |
| class | 탐지된 객체 종류 |
| center_x | 바운딩 박스 중심 X좌표 |
| center_y | 바운딩 박스 중심 Y좌표 |
| width | 바운딩 박스 너비 |
| height | 바운딩 박스 높이 |
| confidence | 객체 탐지 신뢰도 |

## 6. 모의 데이터 수집

노트북 웹캠을 이용해 약 2분간 객체 추적 데이터를 수집했습니다.

다음과 같은 상황을 가정하여 모의 데이터를 수집했습니다.

1. 카메라를 향해 점점 가까워지는 상황 (30초)
2. 카메라에 접근하다가 옆으로 방향을 바꾸는 상황 (30초)
3. 카메라 앞에서 오른쪽에서 왼쪽으로 이동하는 상황 (30초)

수집 결과:
- 전체 추적 기록: 1,051개
- 사람 추적 기록: 908개
- 사람 외 객체 탐지 결과 일부 포함

현재 데이터는 추적 결과의 저장 방식과 좌표 변화를 확인하기 위한 초기 테스트 자료입니다.
추가로 필요한 이동 상황이나 학습 데이터가 있다면 추후 데이터 수집 시 반영할 예정

## 7. 추후 작업 및 개선 사항

라즈베리파이용 코드 및 향후 학습 데이터 수집 코드에서는 사람 외 객체를 인식하지 않도록 수정할 예정입니다.
현재는 집에서 모의 데이터를 수집하다 보니 먼 거리에서 카메라로 접근하는 움직임을 충분히 반영하지 못했습니다. 추후 더 넓은 공간에서 다양한 이동 상황의 데이터를 추가로 수집할 예정입니다.
