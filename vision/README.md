# YOLO11 + ByteTrack 객체 추적

## 1. 개요

YOLO11과 ByteTrack을 이용해 웹캠 영상에서 사람을 인식하고, 객체별 ID와 위치 정보를 추적하는 코드입니다.

현재는 Windows 노트북 웹캠을 이용해 기본적인 추적 기능을 구현했으며, 추적 결과를 CSV 파일로 저장하도록 구성했습니다. 추후 라즈베리파이에 적용할 예정으로, 우선 코드는 PC 환경에서 동작을 확인하고 데이터를 수집하기 위한 초기 버전입니다.

## 2. 구현 내용

- YOLO11n 모델을 이용한 실시간 사람 인식
- ByteTrack을 통한 객체별 ID 부여 및 추적
- `classes=[0]` 설정을 통해 사람만 탐지하도록 제한
- 객체 중심 좌표(X, Y), 바운딩 박스 크기, 신뢰도 추출
- 탐지 시각 및 프레임 번호 기록
- 동일한 프레임에 있는 객체는 같은 시간 정보를 사용하도록 수정
- 프레임 해상도 정보(`frame_w`, `frame_h`) 추가
- 추적 결과를 실행 시각별 CSV 파일로 저장
- 프로그램 종료 시 웹캠 해제

## 3. 실행 환경

- Windows
- Python 3.11
- Ultralytics
- OpenCV
- 노트북 내장 웹캠

필요한 패키지는 프로젝트 최상위 폴더의 `requirements.txt`에 정리했습니다.

```bash
python -m pip install -r requirements.txt
```

`yolo11n.pt` 모델 가중치 파일은 저장소 용량을 고려해 업로드하지 않았습니다. 

### 패키지 설치 과정에서 발생한 문제 (2026.11.09)

실행 환경을 설정하는 과정에서 NumPy와 OpenCV의 버전이 맞지 않아 `numpy.core.multiarray failed to import` 오류가 발생했습니다.

NumPy 버전을 조정하고 Ultralytics를 설치한 이후 웹캠 추적 코드가 정상적으로 실행되는 것을 확인했습니다.

다만 `requirements.txt` 설치 및 의존성 확인 과정에서 기존 Python 환경에 설치된 TensorFlow 관련 패키지와 버전 충돌 경고가 발생했습니다.

- `protobuf 7.36.2`와 TensorFlow 관련 패키지 간 버전 충돌
- `ml-dtypes 0.2.0`과 `tf-nightly` 간 버전 충돌

현재 웹캠 추적 기능은 실행되는 상태이지만 기존 Python 환경의 패키지 충돌이 모두 해결된 것은 아닙니다. 추후 프로젝트 전용 가상환경을 만들어 패키지를 따로 관리할 예정입니다.

## 4. 실행 방법

프로젝트 최상위 폴더(`ai-door`)에서 아래 명령어를 실행합니다.

```bash
python vision/webcam_tracking.py
```

실행하면 웹캠 영상에서 인식된 사람의 바운딩 박스와 추적 ID가 표시됩니다.

웹캠 창에서 `q` 키를 누르거나 터미널에서 `Ctrl+C`를 입력하면 종료할 수 있습니다.

기존에는 실행할 때마다 CSV 파일이 덮어써지는 문제가 있어, 실행 시각을 파일명에 포함하도록 수정했습니다.

## 5. 추적 데이터

CSV 저장 위치:

`data/vision/`

csv 파일은 실행 시간을 기준으로 자동 생성됩니다.
파일명 예시:

`20261109_223500_tracking.csv`

| 항목 | 설명 |
|---|---|
| timestamp | 데이터 기록 시각 |
| elapsed_sec | 프로그램 실행 후 경과 시간(초) |
| frame_id | 프레임 번호 |
| track_id | ByteTrack에서 부여한 객체 ID |
| class | 탐지된 객체 종류 (person) |
| center_x | 바운딩 박스 중심 X좌표 |
| center_y | 바운딩 박스 중심 Y좌표 |
| width | 바운딩 박스 너비 |
| height | 바운딩 박스 높이 |
| confidence | 객체 탐지 신뢰도 |
| frame_w | 웹캠 프레임 너비 |
| frame_h | 웹캠 프레임 높이 |

같은 프레임에 여러 사람이 인식되더라도 동일한 시간 정보가 기록됩니다.
프레임의 너비와 높이도 함께 저장합니다.

## 6. 모의 데이터 수집

초기 데이터 tracking_results(26.11.06.모의데이터): 노트북 웹캠을 이용해 약 2분간 객체 추적 데이터를 수집했습니다.

1. 카메라를 향해 점점 가까워지는 상황 (30초)
2. 카메라에 접근하다가 옆으로 방향을 바꾸는 상황 (30초)
3. 카메라 앞에서 오른쪽에서 왼쪽으로 이동하는 상황 (30초)

수집 결과:

- 전체 추적 기록: 1,051개
- 사람 추적 기록: 908개
- 사람 외 객체 탐지 결과 일부 포함

사람 외 객체도 함께 인식되는 문제가 있었고 같은 추적 ID에서 객체 클래스가 바뀌는 경우도 확인했습니다.

2026.11.09 코드 수정 과정에서 `model.track()`에 `classes=[0]`을 추가해 사람만 탐지하도록 변경했습니다. 수정 이후 웹캠 추적 기능이 정상적으로 작동하는 것을 확인했습니다.
