# 데이터 형식

## 1. 영상 추적 CSV (채원 → 예은)
- 파일명: `YYYYMMDD_HHMMSS_tracking.csv` (실행 시각 자동 생성)
- 해상도: 640×480, 사람(person)만 기록
- 한 줄 = 한 프레임에서 사람 한 명

| 칸 | 설명 |
|---|---|
| timestamp | 기록 시각 |
| elapsed_sec | 실행 후 경과 시간(초) |
| frame_id | 프레임 번호 |
| track_id | 사람 ID (ByteTrack) |
| class | person |
| center_x, center_y | 박스 중심 좌표 (픽셀) |
| width, height | 박스 크기 (픽셀) |
| confidence | 탐지 신뢰도 |
| frame_w, frame_h | 화면 크기 |

## 2. 문 명령 (예은 → 현진)
- 연결: USB 시리얼, 115200bps
- 한 줄에 명령 하나, 끝은 줄바꿈(`\n`)

| 명령 | 뜻 |
|---|---|
| `OPEN` | 문 열기 |
| `HOLD 2000` | 지금부터 2000ms 동안 열림 유지 (사람이 보이는 동안 0.5초마다 다시 보냄) |
| `CLOSE` | 문 닫기 |
| `ALERT 1` | 경고 (0: 안전, 1: 주의, 2: 위험) |

- HOLD 시간이 끝났는데 새 명령이 없으면 ESP32가 스스로 닫기 (라즈베리파이가 멈춰도 문이 계속 열려 있지 않게)
- 닫는 중에 끼임이 감지되면 명령과 상관없이 ESP32가 바로 멈추거나 다시 열기

## 3. 문 상태 (현진 → 예은)
- 0.1초마다 한 줄씩 보냄

```
STATE angle=45 tof1=120 tof2=130 reed=0
```

| 값 | 뜻 |
|---|---|
| angle | 문 각도 (0 = 닫힘) |
| tof1, tof2 | 문틈 거리 센서 값 (mm) |
| reed | 1 = 완전히 닫힘, 0 = 열림 |

## 4. 레이더 값 (현진 → 예은)
- 미정: LD2450 출력 확인 후 추가 (x, y, 속도 예정)
